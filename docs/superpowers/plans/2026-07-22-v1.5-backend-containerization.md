## 3. 失败回滚路径

### 3.1 Commit 1 失败(Dockerfile 写错 / build 失败)

- **症状**:`docker compose build kb-ai-backend` exit ≠ 0
- **影响**:Commit 2 依赖 Commit 1;若 Commit 1 失败,Commit 2 不能开始
- **回滚**:删除 Dockerfile,重写;不需 git revert(commit 1 可能还没 commit)

### 3.2 Commit 2 失败(compose 集成后服务启动失败)

- **症状**:`docker compose up kb-ai-backend` healthy 失败 / 端口冲突
- **影响**:Commit 3 依赖 Commit 2
- **回滚**:`git revert <commit-2-sha>`;compose 恢复 4 service;保留 Commit 1(Dockerfile 文件但不被引用)

### 3.3 Commit 3 失败(.bat 改动后启动链路不通)

- **症状**:start.bat 第 6 步 `docker compose up -d kb-ai-backend` exit ≠ 0;或 stop.bat 第 1 步 stop 后容器残留
- **影响**:无后续 commit 依赖;可独立回滚
- **回滚**:`git revert <commit-3-sha>`;.bat 恢复 host python 路径

### 3.4 Commit 4 / 5 失败(文档或测试写错)

- **症状**:文档渲染错 / pytest fail
- **回滚**:删文件 + 重写,或 git revert

### 3.5 Commit 6 失败(版本号/CHANGELOG 同步错)

- **症状**:`cat version` 不返回 1.5.0 / CHANGELOG 顶部段缺失
- **回滚**:`git revert <commit-6-sha>`;重新做收口

### 3.6 全链路回滚

若 v1.5.0 整体不可接受:
1. `git revert <commit-1-sha>...<commit-6-sha>`(范围 revert)
2. 验证:`docker compose config` 仍正常(4 service);start.bat/stop.bat 回到 host python 路径
3. version 回 1.4.0 + CHANGELOG 删除 v1.5.0 段
