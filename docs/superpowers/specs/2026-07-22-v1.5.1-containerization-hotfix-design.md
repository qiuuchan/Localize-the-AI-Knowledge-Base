## 2. 文件级变更详情

### 2.1 Item 1 · Dockerfile hotfix(CPU torch + pwsh)

`E:/docker/backend/Dockerfile` 关键改动:

```dockerfile
# builder stage:CPU-only torch(主索引)+ PyPI 补充
RUN pip wheel --wheel-dir=/wheels \
    --index-url https://download.pytorch.org/whl/cpu \
    --extra-index-url https://pypi.org/simple \
    -r backend/requirements.txt

# runtime stage:动态检测 libicu(适配 bookworm=72 / trixie=74)
RUN apt-get update && \
    LIBICU_PKG=$(apt-cache search '^libicu7[0-9]' 2>/dev/null | head -1 | awk '{print $1}') && \
    apt-get install -y --no-install-recommends \
        curl sqlite3 wget ca-certificates "${LIBICU_PKG}" && \
    rm -rf /var/lib/apt/lists/*

# PowerShell 7.4 LTS(GitHub release tarball 直链,无需 Microsoft repo)
ARG PWSH_VERSION=7.4.0
RUN mkdir -p /opt/microsoft/powershell/7 && \
    wget -q "https://github.com/PowerShell/PowerShell/releases/download/v${PWSH_VERSION}/powershell-${PWSH_VERSION}-linux-x64.tar.gz" -O /tmp/pwsh.tar.gz && \
    ls -la /tmp/pwsh.tar.gz && \
    tar xzf /tmp/pwsh.tar.gz -C /opt/microsoft/powershell/7 && \
    chmod +x /opt/microsoft/powershell/7/pwsh && \
    ln -s /opt/microsoft/powershell/7/pwsh /usr/local/bin/pwsh && \
    pwsh --version && \
    rm /tmp/pwsh.tar.gz
```

```python
def run_ps(script_path, args=None, cwd=None, timeout=300):
    # v1.5.1:容器环境无 host PS 脚本时优雅降级
    if not Path(script_path).exists():
        return {
            "stdout": "",
            "stderr": f"script not found: {script_path}",
            "returncode": 0,
            "json": None,
            "skipped": True,
        }
    # ... 原有逻辑
```

### 2.3 Item 3 · health.py 降级返回

`E:/backend/api/health.py` 关键改动:

```python
@router.get("/health")
def get_health():
    # ... cache 检查
    result = run_ps(root / "scripts" / "health-probe.ps1", ...)
    # v1.5.1:host PS 脚本不存在(容器环境)→ 返回降级状态,不算失败
    if result.get("skipped"):
        return {
            "status": "degraded",
            "mode": "container",
            "note": "host health-probe.ps1 not available in container; external probes skipped",
            "timestamp": datetime.now(timezone.utc).isoformat(),
        }
    # ... 原有错误处理
```
