## 7. Mac 端常见问题速查(实战时优先看这里)

### 7.1 docker 镜像 arm64 缺失

**症状**:`docker compose up` 报 `no matching manifest for linux/arm64/v8 in the manifest list entries`

**修法**:
```bash
# 看镜像支持的平台
docker manifest inspect langgenius/dify-api:1.0.0 --verbose

# 选项 A:改 docker-compose.yml 用别的 tag
# 选项 B:用 docker buildx build 拉多架构镜像
# 选项 C:反馈给 maintainer(可能要更新 docker-compose.yml 锁版 tag —— 这是 §7.2 红线 #4,需 maintainer 授权)
```

### 7.2 Gatekeeper 拦截

**症状**:双击 `start.command` 弹"无法打开,因为它来自身份不明的开发者"

**修法**(用户操作,不是代码):
```bash
xattr -d com.apple.quarantine start.command stop.command
chmod +x start.command stop.command
```

或 README 加操作说明:右键 → 打开方式 → 打开(只需一次)。

### 7.3 virtiofs + Dify SQLite lock

**症状**:Dify worker 报错 `database is locked`,聊天时偶发 500

**修法**:
```yaml
# docker-compose.yml 临时绕过(不动 .yml 主配置,新建 override)
# docker-compose.override.yml
services:
  dify-api:
    volumes:
      - ./data:/app/api/storage:delegated   # macOS delegated 模式
  dify-worker:
    volumes:
      - ./data:/app/api/storage:delegated
```

### 7.4 PowerShell 命令找不到

**症状**:`pwsh: command not found`

**修法**:
```bash
brew install --cask powershell
# 或 Microsoft 官方 .pkg
```

### 7.5 osascript 中文乱码 / 弹窗失败

**症状**:`stop.ps1` 弹"现在可以拔出"对话框中文乱码或无对话框

**排查**:
```bash
# 测 osascript 本身
osascript -e 'display dialog "测试中文" buttons {"OK"}'

# 看 stop.ps1 走的是哪条分支
pwsh -File stop.ps1 -SkipBackup -SkipNotice  # 跳对话框
# 终端能打印 = 函数跑通,只是 GUI 弹窗失败(SSH / 无 GUI 会话)
```

**修法**:见 §6 hotfix #2(`Show-KBAINotice` 已有 stdin + heredoc + 中文 escape 兜底,如果还是乱码就是 macOS 系统 locale 问题,`defaults write -g AppleLanguages '("zh-CN")')。

### 7.6 启动后浏览器没开

**症状**:`start.ps1` 跑完 8 阶段但浏览器没开

**排查**:
```bash
# 手动打开
open http://localhost:8000
# 或
pwsh -File scripts/lib/platform-utils.ps1; Get-KBAIPlatform  # 看平台检测对不对
```

**修法**:`Open-KBAIUrl` 函数用 `Start-Process -FilePath 'open' -ArgumentList $Url`,Mac 上应该 work;如果是路径问题,改 `scripts/lib/platform-utils.ps1` 的 `Open-KBAIUrl`。

### 7.7 某个 .ps1 解析失败

**症状**:`pwsh -File X.ps1` 报 `Unexpected token` + 行列号

**优先看**:
1. 是否用了 ` ` 反引号(双引号字符串内)— 改用普通括号
2. 是否用了 `??` null-coalescing(PS 6+)
3. 是否在字符串内嵌套 `$variable` — PowerShell 会展开,用 `$($variable)` 避免歧义

如果解决不了,把完整错误粘回去给 maintainer,他会转给 Windows 端修。
