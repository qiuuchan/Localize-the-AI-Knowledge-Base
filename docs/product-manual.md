# KB-AI 使用手册

> **一句话**:装在 U 盘里的私人 AI 助手,问什么答什么,数据全在您自己 U 盘里。

---

## 1. 三步上手

| 步骤 | 操作 |
|---|---|
| ① 插 U 盘 | 插到电脑 USB 口,识别出 `AIAssistant` 卷标 |
| ② 双击启动 | 根目录双击 `start.bat`,等 30-60 秒,浏览器自动打开 |
| ③ 开始对话 | 在输入框打字,按 Enter,看 AI 回复(带 `[1] [2]` 出处) |

**首次启动会要求填 API Key**(一次性):
1. 登录 https://bailian.console.aliyun.com/ → 头像 → API-Key 管理 → 创建
2. 复制 `sk-` 开头的字符串
3. 粘贴到 `.env` 文件里替换 `sk-PLEASE-FILL-IN-...`,保存关闭

---

## 2. 能干什么

| 功能 | 怎么用 |
|---|---|
| **聊天问答** | 像跟人说话一样问,支持多轮(接着问上下文) |
| **文档上传** | 顶部「资料库」→ 上传 Word/PDF/PPT/Excel/图片 |
| **图片识别** | 输入框点 📎 上传菜单照片,AI 看得懂 |
| **答案出处** | 回复下方 `[1] [2]` 角标,点开看原文 |
| **历史对话** | 左滑拉出抽屉,所有对话自动保存 |
| **不知道就说不知道** | 文档里没有的,AI 不胡编,直接告诉您"没找到" |

---

## 3. 怎么问效果最好

| 问法 | 例子 |
|---|---|
| 直接问 | "红烧肉怎么做?" |
| 口语化 | "解腻的菜有哪些?" / "今年新菜是哪些?" |
| 对比 | "对比 A 店和 B 店上个月毛利率?"(自动派强模型) |
| 指定时间 | "2025 年以后发布的 SOP" |
| 加约束 | "请只引用文档原文,不知道就说不知道" |

**答得不准?**:换个说法,或点开调试面板看 AI 从哪些文档找到的。

---

## 4. 状态怎么看

顶部状态栏实时显示:

- 🟢 **在线** — 一切正常
- 🟡 **降级** — 部分功能受限,核心聊天可用
- 🔴 **离线** — 服务挂了,新对话不可用

---

## 5. 拔 U 盘前必做

⚠️ **永远不要直接拔盘**!否则可能损坏数据。

```
powershell -File scripts\safe-eject.ps1
```

5 秒倒计时 → 自动关容器 → 弹窗提示 → 系统托盘弹出 → 物理拔出。

## 6. 常见问题

| 问题 | 回答 |
|---|---|
| **数据安全吗?** | 100% 在您 U 盘本地,大模型只接收问题文字,不会泄露完整文档。 |
| **支持哪些格式?** | Word / PDF / PPT / Excel / TXT / 图片(.jpg .png) |
| **能识别图片吗?** | 能,菜单照片、菜品海报、门头照都行。 |
| **要联网吗?** | 首次安装要联网下镜像。日常用要联网调 AI。**断网仍可翻历史对话**。 |
| **能多员工同时用吗?** | 当前单用户版。 |
| **API Key 在哪申请?** | https://bailian.console.aliyun.com/ → 头像 → API-Key 管理 |
| **U 盘丢了怎么办?** | 知识库就没了,建议每周备份一份到电脑或网盘。 |
| **能换电脑用吗?** | 能,插任何 Windows 10/11 装好 Docker 的电脑即可。 |
| **AI 答错谁负责?** | AI 仅供参考,重要决策请点角标核对原文。 |

---

## 7. 卡住了怎么办

1. 看顶部状态:🟢/🟡/🔴
2. 跑 `powershell -File scripts\health-full.ps1` 看 1 屏体检报告
3. 看 `logs\` 目录最新日志
4. 联系工程师,把体检报告截图 + 日志一起发
